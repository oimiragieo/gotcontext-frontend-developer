# Wayfinder patterns (catalog)

Source adapted from tommyjepsen/awesome-ux-skills `ai-wayfinders`.
Use with [SKILL.md](../SKILL.md) for JARVIS seam mapping.

| # | Pattern | One-liner |
|---|---|---|
| 1 | **Initial CTA** | Scaffolded entry (composer + helpers), not a naked box. |
| 2 | **Example Gallery** | Curated, actionable examples with visible prompts. |
| 3 | **Suggestions** | 3–6 clickable starters; prefer contextual. |
| 4 | **Templates** | Fill-in structures for repeatable tasks. |
| 5 | **Nudges** | One tip at the moment of need. |
| 6 | **Follow-ups** | Next steps after a result. |
| 7 | **Prompt Details** | Show constraints/mode so users learn the system. |
| 8 | **Randomize** | Shuffle safe examples to lower blank-slate pressure. |

## Decision cheat-sheet

| Moment | Reach for |
|---|---|
| First open Chat | Initial CTA + Suggestions |
| First Voice | Nudge (mic/gate) + Consent (trust-builders) |
| Power-user repeat job | Templates |
| After a run/tool | Follow-ups tied to that artifact |
| Teaching limits | Prompt Details + honest cannot-do |

## Universal principles

- Surround input; don't dump prompt engineering on the owner.
- Every example is an entry point, not wallpaper.
- Retire dead suggestions; never advertise undeliverable capabilities.
- Keep galleries off lifeline channels (Telegram/voice) unless tiny and spoken-safe.
